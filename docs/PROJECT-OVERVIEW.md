# Fork overview

This repository is a fork of [hellzerg/optimizer](https://github.com/hellzerg/optimizer).
The Windows utility and its original documentation belong to upstream and its
contributors. This fork does not establish a separate Byens IT product release
or independently verified performance benefits.
